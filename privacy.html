Privacy Policy

Last updated: October 2026

What this app is

ai-clips is a personal automation tool used only by its owner to manage their own YouTube channel and their own Google Sheet.

What data it accesses

With the owner's permission, the app uses Google APIs to read and update the owner's Google Sheet, access files in the owner's Google Drive that the app uses, and upload and manage videos on the owner's YouTube channel.

How the data is used

This data is used only to run the owner's own video publishing workflow. It is not sold, shared with third parties, or used for advertising.

Storage

Login tokens are stored only on the owner's own automation server. Video files are kept temporarily for processing and then deleted.

Google API Services

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. It also uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Removing access

Access can be removed at any time from the Google Account security page under third-party connections.
